# Прогноз стоимости подержанных автомобилей

Разработал модель для оценки рыночной стоимости автомобиля по характеристикам из объявления. Требование к качеству прогноза — **RMSE ниже 2 500**.

[Открыть ноутбук с кодом, графиками и результатами](car_price_project.ipynb)

## Что сделал

- Очистил данные объявлений: обработал пропуски, удалил дубликаты и исключил записи с некорректными ценами и характеристиками.
- Сравнил прогноз средней цены (`DummyRegressor`), линейную модель `Ridge` и градиентный бустинг `LightGBM`. Подобрал гиперпараметры с помощью кросс-валидации.
- Использовал SHAP, чтобы оценить вклад признаков в прогноз. Среди наиболее значимых оказались год регистрации, мощность двигателя и пробег.

## Результат

**LightGBM показал RMSE 1 625,62 на тестовой выборке** и выполнил требование проекта. На кросс-валидации его ошибка составила **1 668,79** против **2 448,01** у Ridge — примерно на **32% ниже**.

**Инструменты** — Python, pandas, NumPy, scikit-learn, LightGBM, SHAP, PhiK, Matplotlib и Seaborn.
